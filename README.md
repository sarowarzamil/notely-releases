# Notely Releases

This is the official distribution repository for Notely, an offline-first Windows desktop note-taking application.

Official stable Windows x64 installers and release notes will be published in the [Releases](https://github.com/sarowarzamil/notely-releases/releases) section. Packaged Notely installations check this public repository for stable releases and show the official release page; Notely never downloads, executes, or installs an update automatically.

Installers may be unsigned. Review each release and any Windows security prompts before installing.

No installer or public release has been published yet.
