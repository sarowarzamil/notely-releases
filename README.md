Packaged Notely installations check this public repository for stable releases and show the official release page. Notely never downloads, executes, or installs an update automatically.

The installer is unsigned. Windows may show an unknown-publisher or SmartScreen warning. Review the release notes and Windows security prompts before installing.

The private source repository is maintained separately at [sarowarzamil/notely](https://github.com/sarowarzamil/notely).
